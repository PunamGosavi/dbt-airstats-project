# DBT Airstats Project

Overview
This project demonstrates building a modern data pipeline using dbt and Snowflake.

Layers

Bronze Layer
- Source ingestion
- Column standardization

Silver Layer
- Data cleaning and transformations
- Handling null values
- Deduplication
- Incremental loading

Snapshots
- SCD Type 2 implementation
- Tracks historical changes

Tech Stack
- dbt
- Snowflake
